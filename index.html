LECCIÓN 01

HTML: la estructura de tu página

HTML significa lenguaje de marcado de hipertexto. Se utiliza para organizar títulos, párrafos, imágenes, enlaces y otros contenidos.

Etiquetas básicas

<h1> Título principal

<p> Párrafo de texto

<img> Imagen

<a> Enlace

<button> Botón

Ejemplo

<h1>Mi primera página</h1>
<p>Estoy aprendiendo HTML.</p>
<a href="https://github.com">Visita GitHub</a>
Consejo: guarda tu archivo principal con el nombre index.html.

LECCIÓN 02

CSS: dale estilo a tu página

CSS significa hojas de estilo en cascada. Controla colores, tamaños, espacios, bordes y la distribución de los elementos.

Ejemplo de CSS

body {
  background: #f5f1ff;
  font-family: Arial, sans-serif;
}
h1 {
  color: #5636a5;
  text-align: center;
}

Propiedades que debes conocer

color Cambia el color del texto.

background Cambia el fondo.

padding Agrega espacio interior.

margin Agrega espacio exterior.

border-radius Redondea las esquinas.

Consejo: utiliza media queries para adaptar el diseño a celulares.

LECCIÓN 03

JavaScript: agrega interacción

JavaScript permite responder a acciones de las personas, validar formularios, mostrar mensajes y actualizar el contenido de una página.

Ejemplo sencillo

function saludar() {
  alert("¡Hola! Bienvenido a mi web.");
}

Conceptos iniciales

let Crea una variable que puede cambiar.

const Crea una constante.

function Define una función.

if Permite tomar decisiones.

addEventListener Escucha eventos como clics.

Practica escribiendo el código y cambiando el mensaje para hacerlo tuyo.
